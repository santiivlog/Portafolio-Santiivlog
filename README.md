# SantiagoDev — Portafolio

Portafolio personal de Santiago: mods y plugins de Minecraft, bots de Discord y desarrollo web. Incluye proyectos propios, colaboraciones, habilidades y precios orientativos.

Sitio: https://portafolio-santiivlog.vercel.app/

## Desarrollo local

**1. Clone the repository**
```
https://github.com/santiivlog/Portafolio-Santiivlog.git
```

**2. Install dependencies**
```
npm install
```

**3. Run dev server**
```
npm run dev
```

**4. Edit config**
```
src/resources/once-ui.config.ts
```

**5. Edit content**
```
src/resources/content.tsx
```
